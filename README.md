# Zlatova Veronika – Portfolio Website

A modern, responsive portfolio website for model and content creator **Zlatova Veronika**.  
Built with React, TypeScript, MUI, and Vite, it showcases photos, videos, and contact information in a clean, animated layout.

🔗 **[Live Demo](https://vadym-mishchenko.github.io/personal-web/)**

---

## 🚀 Tech Stack

- ⚛️ React + TypeScript
- ⚡ Vite
- 🎨 MUI (Material UI)
- 🎞️ react-image-gallery
- 🎬 Framer Motion
